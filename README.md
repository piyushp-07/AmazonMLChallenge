# Amazon ML Challenge — Business Entity Resolution

Team project for the Amazon ML Challenge.

## Problem

Entity resolution across three independent business data sources.

## Team Structure

- Member 1 — Data, Preprocessing & Candidate Generation / Blocking
- Member 2 — Matching Model & Scoring

## Project Pipeline

Data
→ Preprocessing
→ Candidate Generation / Blocking
→ Candidate Pair Features
→ Matching Model
→ Final Entity Matches
→ Submission
